# UNKNOWN Client

A free Fabric client for Minecraft Java 1.21.11: neon glass players, auras and blade trails, a living launcher, and a HUD you can place anywhere.

**Download:** https://unknown-mc-client.web.app, or the newest release on this page.

1. Download the ZIP from Releases.
2. Unzip it anywhere.
3. Run `Start Unknown Client.cmd`.

Windows 10 or 11 and Minecraft Java Edition are needed. Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
